Plantar Pressure Monitoring System for Early Detection of Diabetic Foot Ulcers
Overview

The Plantar Pressure Monitoring System is a biomedical engineering project designed to detect abnormal pressure distribution in diabetic patients using Force Sensitive Resistor (FSR) sensors.
The objective is to identify high-pressure regions that may lead to diabetic foot ulcers, enabling early clinical intervention and reducing the risk of complications.
This project combines embedded systems, biomedical instrumentation, signal acquisition, and digital signal processing for real-time plantar pressure analysis.

Objectives
- Acquire plantar pressure data using FSR sensors
- Process sensor signals in real time
- Reduce sensor noise using digital filtering
- Visualize pressure distribution
- Detect abnormal pressure regions
- Generate data for future AI/ML analysis

Problem Statement

Diabetic neuropathy reduces sensation in the feet, making patients unaware of excessive plantar pressure.

Continuous monitoring allows clinicians to identify high-risk regions before ulcers develop.
